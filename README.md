# Geometry Calc — ЛР №2 (вариант 16)

## Описание

Консольное приложение для расчёта геометрических тел: **параллелепипед**,
**тетраэдр** и **шар**. Для тела произвольных размеров и материала
вычисляются объём, площадь поверхности и масса. Результаты сохраняются
в базу данных SQLite и выгружаются в отчёты формата docx/xlsx.

Проект оформлен в виде пакета `geometry` из трёх модулей:

| Модуль | Назначение |
|---|---|
| `geometry/materials.py` | Справочник материалов (плотность, кг/м³) |
| `geometry/shapes.py` | Иерархия классов тел (ABC + наследование) |
| `geometry/storage.py` | SQLite-хранилище и экспорт в docx/xlsx |

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Запуск в Docker

```bash
docker build -t geometry-calc .
docker run -it geometry-calc
```

## Тесты

```bash
pytest tests -v
```

## Краткая справка

- Параллелепипед: `V = a·b·c`, `S = 2(ab + bc + ac)`
- Правильный тетраэдр: `V = a³ / (6√2)`, `S = √3·a²`
- Шар: `V = (4/3)·π·r³`, `S = 4·π·r²`
- Масса: `m = ρ·V`, плотности материалов взяты из справочника модуля
  `materials.py`
